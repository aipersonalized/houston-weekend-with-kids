# Maintaining This Skill

Preserve the useful outcome: realistic Houston family time informed by current local discovery and official weather, with transparent admission and reservation dependencies.

## Review a change

Read the affected entry point, playbook, output contract and linked source. Keep host-specific integration outside the core. Check relative links, metadata, command help, and the distinction between public facts, planning estimates and unsupported private matching. Refresh only affected volatile facts; source integrity alone does not establish freshness or meaning.

Run the documented preview and deterministic tests in `schemas/command-rules.md`. These tests cover source allowlisting, no-write previews, changed-file detection, preservation/recovery after retrieval failure and clean JSON output. For the optional Claude wrapper, use the installed host's plugin validator. Record actual outcomes at the maintenance system available to the maintainer; do not add family records or private logs to the bundle.

## Static scenario walkthroughs

- Complete permitted inputs: discovery → official weather → organizer rules → anchors/breaks → optional comparison → checked result at the supported evidence level.
- Missing dates/categories: retain public research, expose exact gaps and return provisional choices without invented totals or capacity.
- Weather/web failure: explain failed coverage, use verified conditional alternatives, and withhold unsupported readiness claims.
- Fixed visit list or pass-only request: preserve the user's basket and compare it without inventing extra visits.
- No shopping skill: this agent uses the bundled comparison contract; no workspace-relative dependency is required.
- Changed forecast or interrupted work: revisit affected steps, preserve accepted unaffected work, and inspect any uncertain external action before retrying.

Walkthroughs and deterministic tests are separate from model task trials. Run new model trials only when explicitly requested, with agreed data, cost and side effects. Report the tested host/model and observed scope; do not imply universal behavior or compatibility.

## Source maintenance

`assets/source-catalog.json` owns eight fixed official background sources. The optional collector can refresh their full HTTP HTML and derived text locally. Full copies remain Git-ignored and outside the authored MIT material. Honor publisher terms; use official live links when collection is unavailable. Neighborhood events and forecasts require separate current public-web research.

Useful improvements address an observed bad decision, missing source or broken command. Verify the correction with the affected static path and meaningful tool checks; preserve already accepted unrelated behavior.
